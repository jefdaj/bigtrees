Questions

Go ahead and reach out! There’s contact info on my blog. I’m happy answering all sorts of questions from regular people or businesses, even if you think they’re too basic or don’t know quite what you want yet. Some ideas…

  • Can BigTrees help with my thing? It isn’t quite like any of the examples.
  • How can I run a Linux command on my Windows drive?
  • How can I dedup my recordings while being sure not to lose anything accidentally?
  • How much RAM would we need to search so many millions of files?
  • Can you add a particular feature, like a new search option or output format?
  • Can you work with our developers to add a dedup step to our data pipeline?
  • Can you write a faster algorithm for our unique data format?

I try to respond to all inquiries within 3 business days, and answer simple questions straightaway or set up a meeting to talk about more complex ones. If it’s too much to figure out in one meeting, then it’s probably a consulting job. Otherwise it’s just a quick, free thing.
