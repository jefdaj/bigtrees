Download

The latest version is v0.15. It’s a pre-release, suitable for adventerous users willing to double check things themselves. Here are the binaries:

  • Linux x86_64
  • MacOS coming soon

See the GitHub release page for details.

Download the binary file, give it execute permissions, and move it somewhere on your PATH. For example:

chmod +x ~/Downloads/bigtrees
mv ~/Downloads/bigtrees ~/.local/bin/
which bigtrees

You can echo $PATH to see the options, then use which bigtrees or bigtrees version to check that you got it.
